## 📋 Problem Description

You may have noticed that when we call the print() function, we put variables and strings inside of the parentheses. That's because a function can be defined with parameters.

In the above code, we defined a function called greet that takes a parameter called name. We call the function by passing in "Alice" as the argument. Inside the function, we concatenate the string "Hello, " with the name parameter (we can combine strings with the + operator). We then print the result. The power of parameters is that we can pass different values to the function and get different results. This allows us to reuse code without having to type it all out from scratch each time.

When calling a function, you can pass values, variables, or expressions as arguments to the function.

When a function is called, the arguments are the data you pass into the function's parameters. In the example above, the parameter is name and the argument is "Alice". If we next call the function by passing in "Bob" as the argument, the parameter is still name, but the argument is now "Bob".
